This one renders a single comment and recursively renders its replies. Parameters: comment — Comment object user_votes — dict of { comment_id: vote_value } album_id — int depth — how deep this comment is nested (0 = top-level) We stop indenting visually after depth 3 to keep it readable. ══════════════════════════════════════════════════════════════════════════ #} {% macro render_comment(comment, user_votes, album_id, depth) %} {# Sort the replies: 1. Any reply with score >= 20 is "pinned" and always shown first, in score order. 2. The remaining replies are sorted by score descending. 3. Of the remaining, the top 4 are shown by default. 4. Beyond 4, replies are shown in chronological order and collapsed. We do the sorting and splitting here in the template using Jinja2 filters. #} {# Separate pinned (score >= 20) from the rest #} {% set pinned_replies = comment.replies | selectattr('score', 'ge', 20) | sort(attribute='score', reverse=true) | list %} {% set normal_replies = comment.replies | rejectattr('score', 'ge', 20) | sort(attribute='score', reverse=true) | list %} {# Of the normal replies, show the top 4, collapse the rest #} {% set visible_normal = normal_replies[:4] %} {% set overflow_normal = normal_replies[4:] | sort(attribute='created_at') | list %}
